# Chapter 23, Challenge 1: `switch`

`clox` now supports:

```text
switchStmt     → "switch" "(" expression ")" "{" switchCase* defaultCase? "}" ;
switchCase     → "case" expression ":" statement* ;
defaultCase    → "default" ":" statement* ;
```

The switch value is stored in a hidden local slot. Each case loads that value,
evaluates its case expression, compares them with `OP_EQUAL`, and conditionally
jumps over the case body. A matching body jumps to the end of the switch, so
there is no fallthrough.
