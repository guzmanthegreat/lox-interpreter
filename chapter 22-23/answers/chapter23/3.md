# Chapter 23, Challenge 3: A New Control-Flow Feature

I would add a `repeat` expression that evaluates a body a specified number of
times and returns the last value:

```lox
var total = repeat 3 { 10 };
```

This is useful for small deterministic tasks and can be compiled using the
same loop and counter instructions as `for`. It is more readable than manually
creating a counter, while remaining simple enough that it does not introduce
new control-flow behavior such as fallthrough or implicit exceptions.
