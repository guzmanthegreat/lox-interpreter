# Lox Interpreter — Java Foundations

This stage contains the Java tree-walk interpreter foundations. The challenge
notes are in `chapter_8-9_challenges.md`, and the source is in `jlox/com`.

Chapter 8 adds variables, statements, and scopes. Chapter 9 adds conditions
and loops. This source also contains later features from the book.

From `jlox`, build and run:

```sh
javac com/craftinginterpreters/lox/*.java
java com.craftinginterpreters.lox.Lox
```
